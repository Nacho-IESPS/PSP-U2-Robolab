# Material audiovisual del Reto 1

En esta carpeta deben guardarse estos dos archivos de la versión 2:

- `Reto1_Pasillos.mp4`: vídeo de referencia con el funcionamiento correcto.
- `Vista_Referencia.png`: captura de referencia de la simulación.

Los dos archivos se encuentran en el ZIP de la versión 2 del proyecto, en la carpeta `referencia/`.

**Importante:** el vídeo muestra el resultado esperado sin entregar el código de la solución. No subir aquí ningún `.class`, `.jar` ni archivo con la implementación correcta.

Para añadir los recursos, abre esta carpeta en GitHub y usa **Add file → Upload files**, o copia ambos archivos a tu clon local y haz `git add referencia/`, `git commit` y `git push`.
